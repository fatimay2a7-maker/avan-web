# آوان وب — قالب نمونه‌کار وب‌سایت شرکتی

## اجرا
1. فایل ZIP را استخراج کنید.
2. `index.html` را در مرورگر باز کنید.
3. برای توسعه راحت‌تر، می‌توانید پوشه را در VS Code باز کرده و از افزونه Live Server استفاده کنید.

## فایل‌ها
- `index.html`: ساختار و محتوای صفحه
- `style.css`: استایل‌ها و واکنش‌گرایی
- `script.js`: منوی موبایل، انیمیشن ورود، سال فوتر و اعتبارسنجی فرم

## پیش از انتشار
- نام برند، ایمیل و متن‌های نمونه را با اطلاعات واقعی خودتان جایگزین کنید.
- نمونه‌کارهای نمایشی را با پروژه‌های واقعی خود جایگزین کنید یا واضح برچسب «مفهومی» بزنید.
- فرم فعلی به سرور متصل نیست؛ برای دریافت واقعی پیام‌ها باید آن را به بک‌اند یا سرویس فرم متصل کنید.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای استفاده کاملاً آفلاین، فایل فونت را میزبانی محلی کنید.
- دسترس‌پذیری، عملکرد و سئو را پیش از ارائه به مشتری آزمایش کنید.
